Loading Page:
	Check server health and Renpy Config Healthy; auto-spawn local_server

Workspace Select Page (auto-enter Main if recent[0] exists and check passes):
	List of workspaces opened before, Click to open or delete
	Import new workspace, select path to open
	Create new workspace, select path to create
	if open: check workspace
		if valid: setup_or_repair workspace
		if not valid: choose setup_or_repair or create_or_reset
	else: create_or_reset
	On success: bump recent_workspaces last_opened_at, persist Ren'Py config

Main Page:
	Back Button (back to Workspace Select)
	Workspace Settings (route)
	History (separate page)
	Config Settings (route)
	Options (if last msg is assistant message with options)
	Input (if agent is not locked)
	Last Assistant Message (if any)
	POST /v1/turn with workspace_path + answer_with_choices
	Cancel = disconnect SSE

Workspace Setting Page:
	read system prompt, update, reset (packaged Ren'Py default string — NOT server hard-reset / empty-only create)
	read memory, update
	No history here

History Page:
	list dates, read one day, clear history (POST history/reset); pass workspace_path

Config Page (single form):
	local_server fields → PUT /v1/config
	Ren'Py language → ~/.amnesia-agent-renpy/config.json
	Reset local server → POST /v1/config/reset
	Reset Ren'Py → rewrite home JSON defaults

Notes:
	Not allow close app when agent busy.
	On close when idle: POST /v1/shutdown then exit.
